# ATM SYSTEM

## PROJECT OVERVIEW

This is a simple ATM System project developed using Python.

The project simulates basic ATM operations such as account verification, PIN verification, checking balance, depositing money, withdrawing money, changing PIN, viewing a mini statement, logging out, and exiting the ATM system.

The project is designed as a beginner-friendly Python project.

## TECHNOLOGIES USED

* Python
* VS Code
* GitHub

## PROJECT FILES

1. atm_system.py
   Main Python file that controls the ATM system and menu.

2. accounts.py
   Contains the account details of different users, including:

   * Account number
   * Account holder name
   * PIN
   * Account balance

3. transactions.py
   Handles transaction data and displays the mini statement.

4. atm_functions.py
   Contains functions for:

   * Checking balance
   * Depositing money
   * Withdrawing money
   * Changing PIN

5. README.txt
   Contains information and documentation about the project.

## FEATURES

1. Multiple Accounts
   The system contains multiple user accounts.

2. Account Number Verification
   The user enters an account number and the system checks whether it exists.

3. PIN Verification
   The user gets a maximum of three attempts to enter the correct PIN.

4. Account Blocking
   After three incorrect PIN attempts, the account is blocked for that session.

5. Check Balance
   Users can check their current account balance.

6. Deposit Money
   Users can deposit money into their account.

7. Withdraw Money
   Users can withdraw money if sufficient balance is available.

8. Change PIN
   Users can change their current PIN by entering and confirming a new PIN.

9. Mini Statement
   Users can view their deposit and withdrawal transactions along with the final balance.

10. Logout
    Users can log out from the ATM system.

11. Exit
    Users can exit the ATM system.

## HOW TO RUN

1. Open the project folder in VS Code.

2. Make sure all Python files are in the same folder.

3. Open the VS Code terminal.

4. Run the main file using:

   python atm_system.py

5. Enter an account number.

6. Enter the correct PIN.

7. Select an option from the ATM menu.
